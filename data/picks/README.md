# picks/ — 机器可读的推荐档案

这个目录由 `github-daily-picks` skill 每天写入一份 `YYYY-MM-DD.jsonl`（一行一个条目，推荐与淘汰都记）。

**字段定义见 `../README.md`**，此处不重复。

## 用途

- 画趋势图（每日 S 档数量、风险分布）
- 统计方向分布（哪个 topic 出的项目多）
- 复盘"某天为什么没推荐某仓库"（对照 `drop_reason`）

## 注意

- 这是**派生产物**，丢了不影响日报；**不可再生的原始数据是** `../seen.jsonl` 与 `../snapshots/`。
- 文件名日期必须与内部 `date` 字段一致。
- 尚未运行过：本目录会在第一次跑日报时自动生成首个文件。
