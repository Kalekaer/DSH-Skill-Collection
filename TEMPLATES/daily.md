### 1. {{owner/repo}} · S 档 · {{language}} · {{stars}}★（+{{Δ}}/天）

1. **项目名**：{{owner/repo}}
2. **一句话定位**：这是一个给____用的____，能帮你____。
3. **30 秒判断**：它是啥 ｜ 能帮你干嘛 ｜ 适合你如果 ｜ 不适合你如果 ｜ 风险：{{低/中/高}} ｜ 行动：{{试玩/收藏/研究/放弃}}
4. **基本信息**：仓库地址 ｜ 作者或团队 ｜ 主要语言 ｜ License ｜ Star 数 ｜ 最近更新 ｜ 是否归档 ｜ 是否需要 API Key 或付费
5. **分类标签**：{{领域}} / {{形态}} / {{用途}} / {{成熟度}} / {{上手难度}} / {{风险等级}}（每维取值见下方枚举表）
6. **它到底干啥**：生活类比 → 解决什么痛点 → 核心功能 ≤3 条 → 典型场景 ≤3 条 → **它不做什么**
7. **怎么用**：
   ```bash
   {{真实可执行的安装/运行命令}}
   ```
   {{需要什么环境、是否需要账号/密钥/服务器、支持哪些平台}}
8. **亮点**：为什么值得看 ｜ 和同类比优点 ｜ 和同类比缺点
9. **风险与注意**：按 `SKILL.md` 第七节清单逐项说明
10. **适合谁 / 不适合谁**
11. **学习成本**：看懂 ____ ｜ 跑起来 ____ ｜ 用熟 ____
12. **总结**：{{一句话}} —— 建议{{试玩/收藏/研究/放弃}}

## ⭐ 次级推荐（A 档 · 简条）

- **{{owner/repo}}** — {{一句话是什么}}。为什么：{{具体理由}}。上手：`{{命令}}`。许可与成本：{{License，是否免费/是否需密钥}}。行动：{{试玩/收藏/研究/放弃}}。链接：{{url}}

## 🔗 入口（**每条推荐都要有，末尾要有汇总**）

**每条推荐**（S 档 / A 档都算）在标题下面紧跟一行：

> 🔗 直接打开：https://github.com/{{owner/repo}}

**报告末尾**（在「🧾 运行备注」之后）追加固定格式：

```
---
## 🔗 一键入口

- 🏠 本机工具库总览：`overview.html`（双击打开；搜项目名即可看到它的完整介绍）
- 🔍 今日推荐直链：
  - [owner/repo](https://github.com/owner/repo)
  - [owner/repo](https://github.com/owner/repo)
```

> 为什么要有：日报是给人做决定的。**看到感兴趣的项目，一步就能点开**，不要让人复制粘贴。
