# 截图说明（3 张就够）

> README 里的图位指向这个目录。**只需要 3 张**——不要十几张。
> 拍法：双击 `overview.html` → 浏览器全屏（F11）→ `Win + Shift + S` 截图 → 存成下面这三个文件名。

| 文件名 | 拍什么 | README 里的图注 |
|---|---|---|
| `1-home.png` | **首页顶部**：让「👋 欢迎来到你的开源工具库」+ 项目数量 + 搜索框 + 「🧩 按需求组方案」的场景按钮都在画面里 | 打开即用的个人开源工具库 |
| `2-search.png` | 在搜索框输入 **`我想做AI绘画`**，让结果卡片（图片生成 / 插画 / 工作流）露出来 | 不需要知道项目名字，用需求找工具 |
| `3-workspace.png` | 点开一个工作区（例如「产品设计作业」），拍到右侧面板里的**目标 + 工具列表 + ✅⬜ 进度** | 根据目标组合工具，而不是收藏链接 |

## 拍之前的两点注意

1. **别拍到个人信息**：面板里可能有你自己的备注、或带用户名的路径 —— 拍之前先看一眼，必要时换个工作区拍。
2. **建议宽度**：浏览器窗口 ≥1200px 再截，窄屏会把「按需求组方案」挤到折叠区。

## 拍完之后

把三张图放进本目录，然后：

```powershell
# 确认 README 的图位引用的就是这三个文件名
Select-String -Path ".\README.md" -Pattern 'docs/screenshots'
```

README 里的图位是 Markdown 图片语法，文件放进来即生效，**不需要改任何代码**。
